Project Mission

WebShield is a real portfolio-grade security tool that inspects HTTP behavior, follows same-domain links, and checks for common web risks in a safe, responsible way.

It is intended for authorized testing only and avoids destructive or hostile actions.

  • Same-domain crawling for discovery
  • Security header validation
  • Reflected XSS and SQL injection heuristics
  • Sensitive path checks
  • Historical result storage
